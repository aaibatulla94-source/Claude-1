# PRD — Форма заявки на приобретение семян подсолнечника

**Версия:** 1.0  
**Дата:** 29.05.2026  
**Статус:** Draft  
**Владелец продукта:** Экономист маслозавода

---

## 1. Контекст и проблема

Экономист маслозавода ежедневно вручную заполняет калькулятор рентабельности по каждому входящему предложению от крестьянских хозяйств (КХ). Данные поступают в разрозненном виде — по телефону, в мессенджерах, на бумаге — что приводит к:

- потере времени на сбор и стандартизацию данных;
- ошибкам из-за неполных или неточных сведений;
- отсутствию единого архива заявок для анализа.

---

## 2. Цель

Создать единую веб-форму, которую заполняет сам представитель КХ. После отправки экономист получает структурированный набор данных, достаточный для немедленного расчёта рентабельности закупки без дополнительных уточнений.

---

## 3. Целевая аудитория

| Роль | Действие |
|---|---|
| Представитель КХ | Заполняет и отправляет форму |
| Экономист маслозавода | Получает данные, передаёт на расчёт рентабельности |
| Руководство | Получает итоговое заключение: покупаем / не покупаем |

---

## 4. Scope (что входит в продукт)

### 4.1 Входит

- Веб-форма заявки (одна страница, без авторизации)
- Валидация обязательных полей
- Кнопка отправки, передающая структурированные данные экономисту
- Деловой визуальный стиль

### 4.2 Не входит (v1.0)

- Авторизация и личный кабинет КХ
- Архив и история заявок
- Автоматический расчёт рентабельности внутри формы
- Уведомления по email / SMS
- Мобильное приложение

---

## 5. Структура формы

### Блок 1 — Сведения о хозяйстве

| Поле | Тип | Обязательное |
|---|---|---|
| Наименование КХ | Текст | Да |
| БИН / ИИН | Текст | Нет |
| Контактное лицо | Текст | Да |
| Телефон | Телефон | Да |
| Адрес / местонахождение | Текст | Да |
| Тип дороги до КХ | Выбор: Асфальт / Грунтовая / Смешанная | Нет |

### Блок 2 — Объём и качество сырья

| Поле | Тип | Обязательное |
|---|---|---|
| Объём предложения (тонн) | Число | Да |
| Сорт / гибрид | Текст | Да |
| Год урожая | Выбор: 2022–2025 | Да |
| Масличность (%) | Число, шаг 0.1 | Нет |
| Влажность (%) | Число, шаг 0.1 | Нет |
| Засорённость (%) | Число, шаг 0.1 | Да |
| Место хранения | Радио: Собственный склад / Арендованный / Полевой ток | Нет |

> Засорённость и масличность напрямую влияют на выход масла и себестоимость переработки.

### Блок 3 — Ценовые условия

| Поле | Тип | Обязательное |
|---|---|---|
| Предлагаемая цена (₸/т) | Число | Да |
| Условия оплаты | Выбор: Предоплата 100% / 50% / По факту / Отсрочка | Да |
| Базис поставки | Выбор: EXW / DAP / Иное | Нет |

### Блок 4 — Логистика и сроки

| Поле | Тип | Обязательное |
|---|---|---|
| Расстояние до маслозавода (км) | Число | Да |
| Дата начала поставки | Дата | Да |
| Дата завершения поставки | Дата | Нет |
| Транспорт | Выбор: КХ / Завод / ТЭК / Не определено | Нет |

> Тип дороги учитывается при оценке логистических рисков в сезон.

### Блок 5 — Примечания

| Поле | Тип | Обязательное |
|---|---|---|
| Дополнительная информация | Многострочный текст | Нет |

---

## 6. Поля исключённые из v1.0 и обоснование

| Поле | Причина исключения |
|---|---|
| Суточная интенсивность поставки | Операционная логистика, не влияет на рентабельность |
| Форма собственности земли | Не используется в расчёте, избыточно для КХ |
| Карантинный сертификат | Документарный контроль — отдельный процесс |
| Качественное удостоверение | То же |
| Фитосанитарный сертификат | То же |
| Радиологическое заключение | То же |

---

## 7. Поведение при отправке

1. Пользователь нажимает **«Отправить заявку»**
2. Форма собирает все заполненные поля в структурированный текст
3. Данные передаются экономисту с запросом на расчёт рентабельности
4. Экономист получает готовый пакет данных без необходимости уточнений

---

## 8. Требования к дизайну

- Деловой стиль, без декоративных элементов
- Адаптивная сетка (2–3 колонки на десктопе)
- Обязательные поля маркируются символом `*`
- Подсказки (hint) под полями где нужно пояснение
- Все поля с единицами измерения используют суффиксный бейдж (тонн, %, ₸/т, км)

---

## 9. Метрики успеха

| Метрика | Цель |
|---|---|
| Время заполнения формы представителем КХ | ≤ 5 минут |
| Доля заявок без необходимости уточнений | ≥ 80% |
| Время экономиста на обработку одной заявки | Снижение на 70% vs текущий процесс |
